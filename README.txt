LSC 减肥日常 App

上传到 GitHub Pages：
1. 将本文件夹内的 index.html、app.js、manifest.webmanifest、icon.svg、sw.js 全部上传到仓库根目录。
2. 在仓库 Settings -> Pages 中选择 main 分支和 / (root)。
3. 等待 GitHub Pages 发布完成后，用 iPhone Safari 打开地址。
4. 点击 Safari 分享按钮，选择“添加到主屏幕”。

主要功能：
- 体重、睡眠、步数、饮水记录
- 早餐、午餐、晚餐、加餐及各餐热量
- 每日总热量、目标与剩余热量
- 走路、俯卧撑和身体感受
- 历史记录编辑与删除
- 7天体重趋势和周报
- JSON数据导入导出
- 数据仅保存在当前浏览器

注意：食物热量为估算数据，不是医疗或营养诊断。
